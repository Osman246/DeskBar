# Code of conduct

Be nice. That's mostly it.

DeskBar is a small project that I look after myself, and I want it to be an easy place to ask
questions, report bugs and share ideas. So be respectful, even when you disagree, and if you're
going to criticise something, make it the code and not the person.

Harassment, insults, discrimination and spam aren't welcome here. I'll remove them and block whoever
posted them.

If someone's giving you a hard time, report their comment (**···** → **Report content** → **Report
to repository admins**) and it'll come to me privately.
