# Security

DeskBar runs on your Mac with your permissions, so security problems matter even in a small app.

## Reporting a problem

Please **don't open a public issue**. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/Osman246/DeskBar/security/advisories/new)
instead. Say what you found, which version of DeskBar and macOS you're on, and how to reproduce it.
You'll get a reply within a week, and a fix will go into a new release with credit to you, if you'd
like it.

## Supported versions

Only the [latest release](https://github.com/Osman246/DeskBar/releases/latest) gets fixes.
